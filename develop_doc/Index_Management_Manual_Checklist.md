# Index Management 手动验收

本次未启动 APP、未执行构建，也未对现有索引数据库执行迁移或 Update。
下面的检查由手动运行完成；建议先备份索引数据库，并使用测试 PDF。

## 打开窗口和来源显示

- 不打开任何阅读 PDF，使用 Tools → Index Management… 打开窗口。
- Tools 不再显示 Reindex Current PDF、Clear Annotation Index、Index Database Info 三个独立入口。
- 窗口为可调整尺寸的非模态窗口，默认宽约 1400、高约 800，受屏幕可用空间限制。
- 左边最近来源、右边当前来源，两张表等高，可拖动中间分隔条调整宽度。
- 初次打开只在当前来源中显示数据库中的来源，不自动加入最近来源、阅读标签或旧的暂存行。
- 旧数据库没有来源表时，已有索引按单 PDF 来源显示；仅打开窗口不向数据库写入来源记录。
- 来源明细、数据库信息、任务日志可以查看；选择一行只改变明细，不自动执行索引。

## 添加和编辑

- 添加多个 PDF、添加包含子目录的文件夹、添加不包含子目录的文件夹。
- 新来源显示蓝色和“新增”，尚未 Update 时可以直接移除；数据库内容不变。
- 最近来源支持多选，右键“添加到来源”将所选行加入当前列表，不立即索引。
- 重复添加只定位已有行，不增加重复来源；再次添加待删除来源可以取消删除标记。
- 勾选删除后来源信息灰色，更新标记取消；取消删除后恢复。
- 勾选更新后来源信息加粗；取消更新后恢复。
- 删除与更新不能同时生效；新来源不允许勾选删除、更新和检查修改时间。
- 勾选更新并保留“检查修改时间”：逐个 PDF 比较文件修改时间与对应 PDF 的索引时间。
- 取消检查修改时间：被标记更新的来源强制重新生成索引。
- 新来源或新发现的 PDF 无旧索引时间，直接建立索引。
- 新来源里的 PDF 即使已被其他来源索引，也按磁盘版本重新生成；同一批次去重后只处理一次，不产生重复记录。
- 空的新文件夹暂不能成为已索引来源，应提示并保留其新增状态，不能悄悄提交空来源。
- 文件夹比较内部 PDF 的时间，不能只比较文件夹本身的时间。
- 外部文件变化后，点击“重新检查”仅更新执行计划，不修改数据库。

## 星号与无效变更

- 添加新来源出现 *；再移除这个新来源，其他内容未变时 * 消失。
- 标记删除出现 *；取消所有删除标记后 * 消失。
- 强制更新出现 *；取消更新后 * 消失。
- 勾选更新且检查修改时间，但全部 PDF 未变化时，检查结束后 * 消失，Update 不可用。
- 只修改“检查修改时间”，但没有标记更新时，不出现 *。
- 行选择和查看明细不出现 *。

## Clear、UNclear、Restore

- 先添加新来源并设置已有来源的更新/删除标记，再点击 Clear。
- 列表内容、顺序及原标记不变，但不可编辑，添加/移除操作不可用。
- Clear 变为 UNclear，显示“执行 Update 将清空全部索引数据和来源记录”的提示。
- 此时数据库仍未改变。若数据库本来非空，显示 *。
- 点击 UNclear，恢复此前的来源、新增/删除/更新标记和检查修改时间选项。
- 点击 Restore，放弃所有暂存操作，重新读取数据库，恢复 Clear 按钮并取消 *。
- 待清空状态点击 Update，再次确认才执行清空；取消确认不退出待清空状态。
- 清空成功后右表为空、可重新添加来源、所有标记取消，按钮恢复 Clear。
- 最近来源属于 APP 设置历史，不随索引数据库清空；PDF 文件不受影响。

## Update 和事务

- 两个目录放置同名 PDF（包含仅大小写不同的文件名），Update 应在关闭阅读窗口前提示并阻止执行，详细信息列出完整路径。
- 重名检查覆盖未标记更新的保留来源；文件夹是否包含子目录遵循来源设置。
- 同一完整路径被文件来源和文件夹来源同时包含，不应报重名；标记删除的来源排除，Clear 不检查重名。
- 检查可取消；重名、取消或扫描失败时保留来源编辑、阅读窗口和索引数据库。
- 实际处理前和提交前再次检查，防止外部新增重名文件后仍提交。
- Update 前显示新增、更新、删除数量，以及重叠来源共用索引的说明。
- 更新文件夹时检测新增和消失的 PDF；成功扫描后同步其索引成员关系。
- 同一 PDF 既是单文件来源、又位于文件夹来源中：只保留一份索引。
- 删除其中一个来源，仍被其他保留来源使用的 PDF 索引不删除。
- 来源不可访问、PDF 加密/损坏、批注读取不完整时，整批不提交，原索引保留，暂存编辑保留。
- Update 前要求关闭左右两侧的全部 PDF，包括同一文件的多个 session；选择取消则不开始任务。
- 未保存批注逐一询问保存、放弃或取消；保存仍遵守关闭并重新打开 PDF 的规则，之后再关闭 session。
- 中途取消或保存失败，Update 不执行；之前已经关闭的 session 不自动恢复。
- 实际 PDF 提取在 APP 主进程主线程按页执行，不启动额外进程；界面显示进度并可取消。
- Update 期间禁止从 Open、Open Recent、搜索结果或拖放打开 PDF，禁止重复提交、修改来源及关闭 APP。
- Update 成功、失败或取消后恢复打开操作；PDF 不自动重新打开。数据库准备、复杂单页和最终提交可能短暂等待。
- 索引本身不创建阅读 session、不修改原 PDF；仅 Update 前用户主动选择的保存操作可以修改 PDF。
- 取消处理中任务，等待安全退出后检查原数据库没有部分更新。
- 索引期间文件变化或数据库被其他操作修改，任务应报错而不是覆盖新数据。
- 成功后重新加载来源，新来源变为已有来源，删除来源消失，所有标记和 * 取消。
- 搜索 Sources 列表和索引状态刷新，过期搜索结果清除；手动点击 Search 重新查询。

## 关闭和保存回归

- 有未提交变更关闭窗口，检查 Update、放弃更改、取消关闭三个选择。
- 正在检查时关闭窗口，先安全取消检查，再处理未提交变更。
- 正在 Update 时不能直接关闭/退出 APP；取消并等待任务结束后可以关闭。
- Update 结束后，原有 PDF 保存仍执行“关闭并重新打开”，双视图及全局工具模式继续正常。

## 搜索跳转定位

- 单页及 Continuous 模式双击搜索结果，目标注释进入选中状态，外围定位框闪烁约 2 秒；结束后保留正常选中状态。
- 检查页面底部、多注释密集区、左右双视图，以及尚未打开的 PDF。
- 快速跳转多个结果、切换 session、翻页、缩放或关闭 PDF，不应残留旧定位框或报对象已删除错误。
- Unsupported 注释尽可能显示定位框，不提供原本不支持的编辑能力；目标已删除时提示索引可能过时。
- 定位框不遮盖文字、不拦截鼠标，不修改注释颜色或透明度，也不产生未保存标记。
