# 双阅读区与同步滚动手动验收

本次未启动项目、未构建；以下操作供手动运行时验收。

## 信号和工具栏回归检查

- 启动后检查控制台，不应再出现 `Slot 'ReadingPane::' not found`。
- 先保持单阅读区，依次点击 Text、FreeText、Square、Highlight、Arrow：任意时刻只能选中一个工具，画布光标和实际绘制工具一致。
- 单阅读区完成一次批注新增、点选、属性修改和删除，确认事件响应恢复。
- 并排后在两侧分别操作工具，检查命令作用于带蓝色边框的当前阅读区。
- 开启同步后分别拖动左右滚动条，确认两个方向都能带动另一侧；关闭同步后恢复独立滚动。

## 打开和布局

- 依次打开 A、B、C，当前显示 C、上次查看 B。勾选 View → Side by Side：左侧显示 C，保留 A/C 标签；右侧显示 B。
- 拖动中间分隔条，两侧保持原来的阅读位置。
- 点击右侧空白阅读区，再用 File → Open 打开新文件：文件在右侧打开。
- 普通 Open 打开已有文件：定位到已有视图，不增加重复标签。
- 右键标签 → Move to Other Pane：移动到另一侧；未并排时自动开启并排，不额外移动其他文件。
- 右键标签 → Open in Other Pane：另一侧增加同一 PDF 的独立阅读标签。
- 取消 Side by Side：右侧标签合并到左侧，原当前标签保持选中，文件不关闭。
- 再次开启并排：当前文件在左，最近查看的另一个标签移到右侧。

## 当前阅读区与批注

- A 选择 Highlight，切换到 B 后仍保持 Highlight；B 选择 Square，切回 A 后保持 Square。
- 在同一阅读区切换不同文件标签、新建同文件第二视图、移动标签、合并左右布局，工具模式均保持。
- 翻页、书签/锚点跳转、搜索结果跳转及阅读历史跳转，不应自动切回 Text。
- 保存并重新打开文档后，工具模式保持；主动选择 Text 或按 Esc 才退出添加模式（再次点击当前工具、原有空白处右键双击退出操作也保留）。

- 当前阅读区使用蓝色边框；点击、键盘操作、滚轮操作可以切换当前阅读区。
- 页码、缩放、Continuous、批注工具、Annotations、Navigation 跟随当前阅读区。
- 左右两个不同文件的批注操作、撤销和未保存状态互不影响。
- 同一 PDF 的两个视图可以分别定位、缩放、选中批注，并分别切换 Single Page / Continuous。
- 同一 PDF 中新增、修改、删除、撤销批注，另一侧刷新批注并保持阅读位置；两个标签的未保存标记一致。
- 两侧显示同一 PDF 的同一页时，也检查批注增加、属性修改和删除后的刷新。
- 在 FreeText 编辑过程中切换阅读区或标签，检查已输入内容得到提交。
- 搜索结果、书签和锚点跳转使用正确的文件及当前视图。

## 同步滚动

- 两侧均打开 PDF 且都为 Continuous 时，Sync Vertical Scrolling 才可用。
- 左侧定位第 10 页、右侧定位第 12 页，再开启同步：开启时不跳页。
- 滚动任意一侧，另一侧保持约两页的偏移；反向滚动也能跟随。
- 检查滚轮、拖动滚动条、Page Up / Page Down、中键拖动。
- 同步跟随不会改变当前阅读区，工具栏和侧边栏仍对应操作的一侧。
- 分别使用不同缩放、不同页高的文件，检查按页内位置跟随。
- 滚动到顶/底不越界、不循环抖动；返回可映射的位置后继续跟随。
- 缩放任一侧、拖动分隔条或调整主窗口尺寸，检查阅读位置和同步关系保持。
- 取消同步后可以独立滚动。
- 切换任一侧标签、关闭标签、切换 Single Page 或关闭并排时，自动解除同步。

## 保存和关闭

高亮显示另需检查：Effective C++ 中 100% 不透明度的 Multiply 高亮（黄色、紫色）不能遮住文字；River Town 中约 30% 不透明度的高亮仍应正常。分别检查单页、连续和并排模式，以及缩放后显示；仅打开文件不应产生未保存标记。

请使用测试 PDF，并保留原文件副本。

- 同一文件双视图时执行 Save Incremental：必须关闭并重新打开底层 PDF，两个视图均能继续阅读及编辑。
- 同一文件双视图时执行完整保存：保留原有备份/审计/替换流程，关闭旧 PDF 后重开，两个视图恢复位置及缩放。
- 同步状态下保存，保存后继续滚动，检查同步开关和原有偏移保持。
- 保存后两个标签均清除未保存标记，旧批注引用和缓存不会继续使用。
- Save As 使用新路径：共享该文档的所有视图一起转到新文件，并恢复阅读位置。
- Save As 目标为已打开的 PDF 时，提示选择其他文件名，避免覆盖另一个已打开文档。
- 关闭同一文档的一个视图，另一个仍可阅读、编辑和保存，不提示关闭整个文档。
- 关闭该文档最后一个视图时，存在未保存修改才出现保存提示。
- 退出时，同一文档仅提示一次；选择取消后仍能继续阅读和编辑。
- 模拟保存失败或取消保存，检查界面仍可使用，错误信息及备份保留。
